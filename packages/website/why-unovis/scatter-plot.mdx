# Scatter Plot

Real measurements from the [Palmer penguins](https://allisonhorst.github.io/palmerpenguins/) dataset: flipper length
against bill length, colored by species and sized by body mass. Each click picks a different random half of the 342
penguins.

</LibraryComparison>

## What to look for

- **Size encoding.** Unovis scales body mass to point size with a `size` accessor and a `sizeRange`. Chart.js expects
  sizes in pixels, so you scale the values yourself. ECharts takes pixels in `symbolSize`, or maps values to sizes with a
  `visualMap`.
- **Pick other penguins.** Every penguin has a stable `id`, so Unovis moves the points that stay, fades in the new ones
  and fades out the rest, and the axes follow. TanStack Charts keys the points by `id`
  too and animates them the same way (`svgAnimation`).
- **Colors from CSS.** The Unovis example colors each species with the palette's CSS variables
  (`var(--vis-color0)`…), so the same code gives dark mode colors in dark mode.
- **Axis titles.** Unovis takes a `label` on each axis. Recharts needs label positioning and extra margins for the same
  result.
- **Shapes.** Each species has its own shape (`shape`), in the chart and in the legend. Recharts, Chart.js, ECharts and
  AG Charts have the same shapes built in, and so do Observable Plot (`symbol`) and Vega-Lite (`shape`); Nivo's scatter
  plot and TanStack Charts' `dot` draw circles only.
- **Hover.** The Unovis crosshair (`snapMode: 'xy'`) snaps to the point nearest the pointer and draws guide lines to
  both axes. Nivo, AG Charts, Observable Plot (`tip`) and TanStack Charts also pick the nearest point, while Recharts shows a tooltip only
  when the pointer is over one. So does the Vega-Lite demo, which takes the spec's default; a `nearest` selection
  changes that.
