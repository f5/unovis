# Why Unovis

Unovis is an open-source data visualization library built with care for how charts look and how they behave: when you
hover them, when the data changes, when the theme switches and when the labels are long. Rather than taking our word
for it, this section renders **the same data with Unovis and eight of the most popular charting libraries on npm**,
side by side, with the code for each one.

## When another library might suit you better

We'd rather you pick the right tool than the wrong one:

- **Tens of thousands of individual marks.** Unovis renders SVG. For a scatter plot with 50,000 points, a Canvas or
  WebGL renderer such as ECharts, Chart.js or AG Charts will be faster.
- **Chart types Unovis doesn't have.** There is no built-in candlestick, radar, funnel or gauge chart. ECharts covers
  all of them.
- **Mouse-wheel zoom on XY charts.** Unovis zooms XY charts by setting `xDomain` from a [Brush](/docs/components/Brush)
  selection ([example](/gallery/view?title=Grouped%20Bar%20with%20Brush%20and%20Interactive%20Legend)). ECharts has wheel
  zoom built in, and Chart.js offers it through an official plugin.
- **Quick exploratory charts.** Observable Plot and Vega-Lite are grammars of graphics with faceting, binning and
  aggregation built in, so exploring a dataset takes a few lines. Unovis has no faceting or data transforms.
- **Keyboard navigation of data points.** AG Charts and Recharts let keyboard users move between data points; Unovis
  doesn't yet.

See [how we compare](/why-unovis/methodology) for the rules we followed, the versions we tested and why some popular
libraries aren't rendered here.
